8. Hướng dẫn từng bước cụ thể. Tôi lần đầu sử dụng docker nên không biết nhiều, bạn có thể viết nội dung câu trả lời dài.

CÁC BƯỚC CỤ THỂ:
1. Kéo các image cần thiết về docker. Cụ thể ở đây là mssql 2022 và mssql-tools:
> docker pull mcr.microsoft.com/mssql/server:2022-latest
> docker pull mcr.microsoft.com/mssql-tools:latest

2. Tạo container chứa CSDL với tên container là qlhssv_db và mật khẩu SA của CSDL là 'Ql_Hssv123'
> docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=Ql_Hssv123" --name qlhssv_db -p 1401:1433 -v qlhssv_db_data:/var/opt/mssql -d mcr.microsoft.com/mssql/server:2022-latest

3. Tạo thư mục chứa các tệp tin backup trong container với đường dẫn '/var/opt/mssql/backups' và cấp quyền cho thư mục.
> docker exec -it qlhssv_db mkdir -p

> docker exec -it qlhssv_db chown -R mssql:root /var/opt/mssql/backups
> docker exec -it qlhssv_db chmod 770 /var/opt/mssql/backups

4. Copy thư mục .bak (thư mục khôi phục CSDL vào container)
> docker cp "D:\backups\backup_290526.bak" qlhssv_db:/var/opt/mssql/backups/

5. Kiểm tra container có đang chạy không
> docker ps --filter "name=qlhssv_db"

6. Xem danh sách logical trong backup
> docker exec -it qlhssv_db /opt/mssql-tools18/bin/sqlcmd -S localhost -U SA -P 'Ql_Hssv123' -C -Q "RESTORE FILELISTONLY FROM DISK = N'/var/opt/mssql/backups/backup_290526.bak';"

7. Khôi phục hoàn chỉnh CSDL
> docker exec -it qlhssv_db /opt/mssql-tools18/bin/sqlcmd -S localhost -U SA -P 'Ql_Hssv123' -C -Q "RESTORE DATABASE [QuanLyHoSoSinhVien] FROM DISK = N'/var/opt/mssql/backups/backup_290526.bak' WITH MOVE N'QuanLyHoSoSinhVien' TO N'/var/opt/mssql/data/QuanLyHoSoSinhVien.mdf', MOVE N'QuanLyHoSoSinhVien_log' TO N'/var/opt/mssql/data/QuanLyHoSoSinhVien_log.ldf', REPLACE;"

8. Kiểm tra các CSDL đang tồn tại trong container
> docker exec -it qlhssv_db /opt/mssql-tools18/bin/sqlcmd -S localhost -U SA -P 'Ql_Hssv123' -C -Q "SELECT name, state_desc FROM sys.databases WHERE name = 'QuanLyHoSoSinhVien';"

	8.1. Kiểm tra thực thể trong CSDL:
	> docker exec -it qlhssv_db /opt/mssql-tools18/bin/sqlcmd -S localhost -U SA -P 'Ql_Hssv123' -C -Q "USE [QuanLyHoSoSinhVien]; EXEC sp_help 'dbo.TaiKhoanNguoiDung';"

	8.2. Kiểm tra 100 hàng đầu tiên trong thực thể
	> docker exec -it qlhssv_db /opt/mssql-tools18/bin/sqlcmd -S localhost -U SA -P 'Ql_Hssv123' -C -Q "SET NOCOUNT ON; USE [QuanLyHoSoSinhVien]; SELECT TOP 100 * FROM dbo.TaiKhoanNguoiDung;"
